## 2. 输入与版本

- 直接读 `handoff/qingtian/song-package.json`，格式 `0.1.0`；其余模型依赖无需安装。
- 含歌词时换成负责人提供的本地完整版。两包的旋律、和声、节奏、段落与描述核心字段一致；不能把两包的数据拼接。
- 所有时间为原曲秒数，区间 `[start,end)`；事件 `time` 是单个时间点。音频起始不裁剪，播放速度先固定1倍。
- 校验 `manifest.json` 的文件哈希与音源哈希；同名《晴天》不代表同一版本。音源不是同一文件时需确认时间对齐，不能仅凭曲名使用。
- `estimated` 可以用于原型，但仍是估计；`unknown/null/valid:false` 不制造新音高或新拍点。整包 `partial` 不要求停用其余有效数据。

## 3. 视觉读取哪些字段

| 读取 | 映射 | 空缺处理 |
|---|---|---|
| `melody.contour[].time/midi_float/valid` | 固定音域映射为线条纵向位置；不要把 Hz 当半音直接线性映射 | 连续音高无效时不跨空白连线；若当前有有效音符，可明确使用音符级位置 |
| `melody.notes[].start/end/midi` | 起音标记、同音重复；音符级旋律备用 | 片段间停顿保留；一帧持续多个采样点不算多次起音 |
| `harmony.segments[].pitch_classes` | C=0 至 B=11 对应环上固定位置；共同音保持、新音渐亮、离开音渐暗 | `unknown/no_chord` 时淡出，不能假设成 C 大三和弦 |
| `descriptions[].applies_start/end` 与 `textures/instruments/genre` | 在应用区间内选择材质/风格预设，跨区间平滑过渡 | 未识别标签使用中性预设；不同模型候选不等同已确认乐器 |
| `descriptions[].emotion` | 按 `scale` 归一化后控制环境运动与配色候选 | Music2Emo 本包量表为1–9，不是0–1；无值时中性，不改变旋律与拍点 |
| `lyrics_context.lyrics[].words[].start/end` | 本地完整版可显示当前字，整句显示在下方 | 没文本或词间空白时清空逐字显示；歌词不触发马达 |

连续位置可在相邻有效帧间插值，但不能跨长缺口或跨无效帧。和声光环、材质、颜色属于项目约定，不能宣称为音乐情绪的唯一解释。

当前眼镜只保证局部彩色近眼窗口。先做屏幕预览和显示适配；舞台空间锁定、全景包围和遮挡需硬件验证后再做。

## 4. 手套读取哪些字段

| 读取 | 输出 | 要点 |
|---|---|---|
| `melody.notes[].start/midi` | 对应音区的手背马达短振 | 每个音符起点触发一次；同音重复需再次触发，不跟每个音高采样点抖动 |
| `rhythm.beats[].time/is_downbeat` | 手腕马达 | 按实际拍点列表触发；确认的第一拍较长，其余较短，强度固定；未知第一拍按普通拍处理 |
| `melody.contour` / 当前音符 | 灯带光点位置与短拖尾 | 低音向手腕、高音向指根；灯带起音与手背马达使用同一音符事件 |

音域上下界、低中高分界、边界缓冲、马达与灯珠编号、普通/第一拍脉冲时长、最小间隔、设备延迟写入共享 `mapping-config`，不要散落在代码里。具体数值当前未实测定稿，由试戴和硬件响应确定；界面应提供调节。

用 `melody.notes` 排队，不能把平均 BPM 变成替代拍点，也不能把音符延音直接变成长时间连续振动。四个马达需独立控制；现有方案用两块 DRV8833 常规双通道驱动，实际接线、电压与 GPIO 由硬件实现核对。

## 5. 同步与事件调度

统一采用原音源播放时间。Unity 可使用音频时钟；浏览器先用播放器时间。播放暂停、跳转、停止、重连都必须纳入同一状态机。

1. 播放：按时钟查当前音符/和弦/描述，提前发送带目标时间戳的设备事件。
2. 暂停/停止：清空或冻结待执行事件并立即关闭马达；不在后台继续震动。
3. 跳转：使旧队列失效，重新定位状态，只调度新位置之后的事件；禁止补发跳过的整段。
4. 重连：清空旧事件、重新对时；对迟到事件设置丢弃策略，避免集中补振。
5. 调整设备时钟偏差、通信延迟和马达响应延迟；是否达标以实测记录为准。

共享配置中的音域映射与音区阈值必须整首固定，不能每帧或每段重新缩放造成同一音高落到不同位置。

## 7. 最小验收

- JSON 能读取；原曲0秒与播放器0秒一致；空值不会导致崩溃。
- 同音重复重新提示；停顿不连线、不额外振动；小节第一拍只改变时长。
- 151.16–151.40秒展示 D4 复核声部；154.47–154.61秒为过渡，随后进入人声。
- 暂停、跳转、停止、断连不会残留马达输出或集中补发。
- 两方记录同一事件的画面时间、发送时间和硬件执行时间，报告实测差异。
- 歌词在公开包中为空也能运行；本地完整版的逐字显示与整句显示分别遵循各自时间范围。
