## 已验证内容

- 合成信号验证静音、单音变化、重复起音、节拍与基本和声。
- 整曲验证原曲时长、事件排序、区间覆盖、数值合法与失败说明。
- 完整基础流程由真实子进程运行；复跑能复用缓存，参数、依赖、模型文件变化使缓存失效。
- 歌词 offset、空时间戳清屏、未知时间、无来源背景、不合法数据、HTML 注入均有回归测试。
- 本地浏览器验证音频加载、播放游标、拖动与桌面/手机布局。

## 下一步工作

1. 建立有标注的多风格测试集：评估旋律音高/八度/起音、和弦区间一致性、拍点/第一拍、段落边界与标签。当前没有准确率结论。
2. 对前奏、间奏、伴唱及多旋律段落评估主旋律候选策略，避免将伴奏周期音误作主奏。
3. 评估模型描述在听障用户中的可理解性；保留情绪估计与用户体验的区别。
4. 若需只输入音频就自动获取歌词/歌曲资料，另实现来源检索或转写流程；当前 SOFA 需要参考文本，背景事实不自动编造。
5. 建立独立映射层，读取歌曲包驱动彩色眼镜、灯带和固定强度马达；测试通信延迟、暂停/跳转/重连与同步。

## 发布与数据

代码与可公开运行指标发布至 GitHub；原曲、分轨、完整歌词和权重只保存在本地。第三方源码不复制进本仓库，由锁定版本的模型准备脚本获取。

自动测试目前在本地执行。GitHub Actions 模板已更新，但现有授权缺少 workflow 写权限，未将模板冒充已启用的 CI。每次修改后只运行相关测试；整曲集成变化才重新进行整曲验收。
